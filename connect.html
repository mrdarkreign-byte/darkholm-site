Java EditionPC, Mac, Linux

1. Open Multiplayer

Launch Minecraft: Java Edition and click Multiplayer on the title screen. Any game version works. You don't need to change versions.

The first time, Minecraft may show a warning about third-party servers. Click Proceed.

2. Add Server

Click Add Server at the bottom of the server list.

Xbox, PlayStation and Switch

Console versions of Minecraft don't have an Add Server button, so they can't type in a server address. Ask in our Discord for help joining from a console.

Trouble connecting

  • Can't connect / timed out: check the address for typos. Bedrock players: make sure the port is 8178.
  • Outdated client or server (Bedrock): update Minecraft to the latest version from your app store.
  • Items look invisible or textures are missing (Java): make sure Server Resource Packs is set to Enabled, then rejoin.
  • Still stuck? Ask in the Discord. Tell us your edition, device and the exact error message.
